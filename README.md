# 🧩 SkillComposer: Generative Skill Composition for LLM Agents

This repository contains the source for the [SkillComposer project page](https://skill-composer.github.io/).

As skill libraries grow, the inference-time bottleneck shifts from *obtaining* skills to *composing*
them — deciding which skills to load, how many, and in what order. **SkillComposer** casts this as
task-conditioned skill sequence prediction: a small constrained autoregressive decoder that resolves
subset, count, and order jointly in a single decoding pass.
